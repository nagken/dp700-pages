# Hands-On Labs - DP-700

> Free Microsoft Learn sandbox modules. Each is 30-90 min and runs in a temporary Fabric trial.

## Implement and Manage

1. **[Get started with Microsoft Fabric](https://learn.microsoft.com/training/modules/get-started-fabric/)** - first Fabric login, workspace creation, item authoring.
2. **[Configure Microsoft Fabric workspace settings](https://learn.microsoft.com/training/modules/configure-workspace-settings-microsoft-fabric/)** - capacity, roles, domain, settings.
3. **[Implement security in Microsoft Fabric](https://learn.microsoft.com/training/modules/implement-security-microsoft-fabric/)** - workspace roles, item permissions, RLS, OLS, sensitivity labels.
4. **[Implement Git integration in Microsoft Fabric](https://learn.microsoft.com/training/modules/implement-cicd-fabric/)** - connect Azure DevOps, branch, commit, sync.
5. **[Implement deployment pipelines in Microsoft Fabric](https://learn.microsoft.com/training/modules/deploy-fabric-items-using-deployment-pipelines/)** - Dev -> Test -> Prod with rules.

## Ingest and Transform

6. **[Ingest data with a Microsoft Fabric pipeline](https://learn.microsoft.com/training/modules/use-data-factory-pipelines-fabric/)** - Copy activity, parameters, scheduling.
7. **[Use Dataflow Gen2 in Microsoft Fabric](https://learn.microsoft.com/training/modules/use-dataflow-gen-2-fabric/)** - Power Query M, destinations.
8. **[Use Apache Spark to work with files in a Lakehouse](https://learn.microsoft.com/training/modules/use-apache-spark-work-files-lakehouse/)** - PySpark, Delta tables, MERGE.
9. **[Get started with Real-Time Intelligence in Fabric](https://learn.microsoft.com/training/modules/get-started-kusto-fabric/)** - Eventhouse, KQL queries, dashboards.
10. **[Get started with Eventstream](https://learn.microsoft.com/training/modules/get-started-eventstreams-fabric/)** - stream from Event Hubs to Eventhouse.
11. **[Get started with Mirroring in Microsoft Fabric](https://learn.microsoft.com/fabric/database/mirrored-database/azure-sql-database-tutorial)** - mirror Azure SQL DB or Cosmos.
12. **[Use OneLake shortcuts](https://learn.microsoft.com/training/modules/use-onelake-shortcuts/)** - link ADLS / S3 / Dataverse without copying.
13. **[Get started with Data Warehouse in Microsoft Fabric](https://learn.microsoft.com/training/modules/get-started-data-warehouse/)** - T-SQL stored procs, cross-DB queries.

## Monitor and Optimize

14. **[Monitor activities in Microsoft Fabric](https://learn.microsoft.com/training/modules/monitor-fabric/)** - Monitoring hub, run history.
15. **[Optimize a Lakehouse for analytics](https://learn.microsoft.com/training/modules/optimize-lakehouse-tables-microsoft-fabric/)** - V-Order, OPTIMIZE, VACUUM, partitioning.
16. **[Get started with Data Activator](https://learn.microsoft.com/training/modules/get-started-data-activator/)** - alert rules from streams + Power BI metrics.

---

## Lab session tips

- Spin up a **60-day Fabric trial** at https://learn.microsoft.com/fabric/get-started/fabric-trial - no Azure subscription needed for most labs.
- Pin the trial workspace early so you don't lose your work between sessions.
- Save sample queries and notebooks to your own GitHub for reuse.
- After each lab, review the related Microsoft Learn doc page (linked from the module) for production-ready patterns.
