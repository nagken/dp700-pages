# Official Practice Assessment - DP-700

> Always take the official Microsoft practice assessment before sitting the exam. It is the closest available analog to the real exam experience.

## Official practice link

- **[Official Microsoft DP-700 Practice Assessment](https://learn.microsoft.com/credentials/certifications/fabric-data-engineer-associate/)**
  - Free, multiple-choice + scenario items
  - Detailed explanations linked to Microsoft Learn
  - Retake unlimited
  - Score report identifies your weakest domains

## Pre-exam readiness checklist

- [ ] Read the [skills measured study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-700) end-to-end.
- [ ] Complete every Microsoft Learn module on the [Fabric data engineer career path](https://learn.microsoft.com/training/courses/dp-700t00).
- [ ] Spin up a [60-day Fabric trial](https://learn.microsoft.com/fabric/get-started/fabric-trial) and complete the hands-on labs in [15-hands-on-labs.md](15-hands-on-labs.md).
- [ ] Score **>= 80%** on the official practice assessment, twice in a row, without re-reading explanations.
- [ ] Review every page in this study guide; rebuild every Mermaid diagram from memory.
- [ ] Drill the [Copilot Quiz](17-copilot-quiz.md) modes for at least one full session per domain.
- [ ] Skim [14-pitfalls.md](14-pitfalls.md) the morning of the exam.

## Booking the exam

- Schedule via the [DP-700 exam page](https://learn.microsoft.com/credentials/certifications/exams/dp-700/).
- Online proctoring via Pearson VUE: clean desk, government ID, quiet room, webcam on.
- 100 minutes, ~40-60 questions (varies). Passing score 700 / 1000.
